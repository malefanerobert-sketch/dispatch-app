Shared AI key

One DigitalHouse-owned key powers the Agent for every Dispatch user — match scoring, CV/cover letter/motivational letter drafting, reading a user's Watched pages, and applying on their behalf. Users never see or manage this (they only ever see the word "Agent" in the app); the cost is recovered through their subscription, not billed to their own accounts.

This is used for match scoring and for reading a user's Watched pages to find job postings — the default here is Claude Sonnet 5 for Anthropic / GPT-4o-mini for OpenAI. Paste any valid model string from your provider to override the default. Anthropic retires older model snapshots periodically — if scoring or page-reading silently stops working, check whether the model string here is still current.

This key is stored in dispatch_settings and read directly by the Railway worker (discoverWatched.js/apply.js) on every run — no further backend change is needed when you update it here.
